Intelligent Personal Expense Categorization: Rule-Based vs. Machine Learning

This module provides empirical evaluation for our 3rd-year engineering research investigation. We evaluate three categorization paradigms: Manual Categorization (human cognitive baseline), Rule-Based Keyword Matching, and Machine Learning Classification (TF-IDF vectorizer + Logistic Regression) on an independent benchmark test set of real-world expense descriptions.
